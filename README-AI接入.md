# 法护启航 · AI 大模型接入说明

> AI 法律助手「法小航」采用**双通道**设计：
> - **🧪 离线演示模式（默认）**：内置 6 大高频场景 + 8 类关键词兜底回答，零网络、零成本，答辩断网也能用；
> - **🎓 DeepSeek 云端模型模式**：填入 API Key 后由真实大模型回答**任意法律问题**，请求失败自动回退离线演示。
>
> 本文档介绍如何开启云端模型模式。无需后端、无需代理、无需 GPU。

---

## 一、架构

```
浏览器 index.html（AI 助手页）
   │  点 ⚙️ 设置 → 选择「🎓 DeepSeek（云端模型）」→ 填入 API Key
   ▼
https://api.deepseek.com/v1/chat/completions   （DeepSeek 官方，OpenAI 兼容接口，浏览器直连）
```

- 页面直接调用 DeepSeek 官方接口，**本项目不包含任何后端服务**，也不需要自己部署模型。
- 接口为通用 **OpenAI 兼容协议**：把「服务地址 / 模型名称 / API Key」换成其他兼容服务，即可接入任意大模型（见第四节）。
- 未配置 Key、未联网或请求出错时，自动回退到离线演示回答，演示流程不会中断。

---

## 二、接入步骤（约 3 分钟）

### 1. 获取 DeepSeek API Key
1. 访问 [platform.deepseek.com](https://platform.deepseek.com) 注册 / 登录；
2. 完成实名认证并充值（按量计费，演示咨询用量很小，余额少量即可）；
3. 在「API Keys」页面创建一个 Key，形如 `sk-xxxxxxxx`，复制保存（**只显示一次**）。

### 2. 在网页中配置
1. 双击打开 `index.html`，进入底部导航「**AI 助手**」；
2. 点右上角 **⚙️** 打开「AI 模型接入设置」；
3. 模式选择 **🎓 DeepSeek（云端模型）**；
4. 确认三项配置（一般保持默认）：
   - **服务地址**：`https://api.deepseek.com`（代码会自动补全 `/v1`）
   - **模型名称**：`deepseek-chat`（也可填 `deepseek-reasoner` 使用推理模型）
   - **API Key**：粘贴第 1 步的 `sk-...`
5. 点 **🔌 测试连接**：
   - 显示绿色「✅ 已连接！模型 deepseek-chat 可用」即成功；
   - 显示红色失败提示，按第五节排查；
6. 点 **💾 保存并应用**，回到对话即可自由提问任何法律问题。

> 配置保存在**本机浏览器** localStorage（键 `deepseek_cfg_v1`），刷新 / 重开页面仍然有效；不会上传到任何服务器，代码中也不内置任何 Key。

### 3. 使用与切回
- 页面顶部状态点：🟢「DeepSeek 已接入」/ ⚪「离线演示模式」；对话右上角标签同步显示 `🎓 DeepSeek` / `● 离线演示`。
- 想切回离线演示：⚙️ → 选「🧪 离线演示模式」→ 保存即可，无需删除 Key。

## 三、工作机制（改代码前了解）

| 环节 | 说明 |
|---|---|
| 请求地址 | `POST {服务地址}/v1/chat/completions`（OpenAI 兼容） |
| 请求内容 | `system` 系统消息（「法小航」角色：要求引用法条、分步骤、不足先追问、提示 12348、附免责声明）+ 最近 **12 轮**对话历史 |
| 参数 | `temperature 0.7`、`top_p 0.9`、`max_tokens 1024`、非流式 |
| 测试连接 | `GET {服务地址}/v1/models`，校验模型名是否在可用列表 |
| 超时处理 | 120 秒超时；请求失败 / 网络错误时，当前气泡提示原因，并**自动追加一条离线演示回答** |
| 鉴权 | 有 Key 时带 `Authorization: Bearer <Key>`；本地模型可不填 |
| 相关代码 | `FUZI_CFG`（配置）、`FUZI_SYS`（系统提示）、`askModel()`（请求与回退）、`testFuziConnection()`（测试连接）；变量名 `FUZI` 为历史命名，界面均显示 DeepSeek |

## 四、接入其他 OpenAI 兼容服务（进阶）

设置弹窗里的三项配置可指向**任何 OpenAI 兼容接口**，无需改代码：

| 目标 | 服务地址示例 | 模型名称示例 | 备注 |
|---|---|---|---|
| DeepSeek（默认） | `https://api.deepseek.com` | `deepseek-chat` | 需官方 API Key |
| 本地 vLLM 服务 | `http://127.0.0.1:8000/v1` | 与 `--served-model-name` 一致 | Key 随意填；见下方 CORS 说明 |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` 等 | 需设置 `OLLAMA_ORIGINS=*` |
| 其他云端兼容服务 | 以各厂商文档为准 | 以各厂商文档为准 | 注意计费与隐私条款 |

**CORS（跨域）注意**：用浏览器直接打开本地 `index.html`（`file://`）时，请求来源为 `null`：
- vLLM 启动需加参数：`--allowed-origins "*"`（或 `"null"`）；
- Ollama 需设置环境变量 `OLLAMA_ORIGINS=*` 后重启；
- DeepSeek 等云端服务已允许浏览器直接调用，无需处理。
- 若目标服务无法开启 CORS，才需要自建一个简单的转发代理（本仓库当前不含后端代码；早期版本曾使用 FastAPI 代理方案）。

## 五、常见问题排查

| 现象 | 原因与处理 |
| --- | --- |
| 测试连接 ❌，提示连接失败 / 401 | API Key 错误、未复制完整，或账户欠费；到 platform.deepseek.com 核对 Key 与余额 |
| HTTP 404 / 模型列表里没有该模型 | 模型名称拼写错误，默认应为 `deepseek-chat`；测试连接成功提示中会列出可用模型名 |
| HTTP 400 | 请求参数被服务拒绝（如模型名与服务不匹配）；核对模型名称 |
| 提问后提示「暂时无法获取回答」并自动回退 | 网络不通 / 超时 / 服务繁忙；页面会自动给出离线演示回答，可稍后重试 |
| CORS / 跨域报错 | 仅出现在自建 / 本地服务：按第四节配置 `allowed-origins`；DeepSeek 云端不会出现 |
| 换了浏览器或电脑要重新填 Key | 配置存在各自浏览器的 localStorage 中，属于预期行为 |
| 想彻底清除配置 | ⚙️ 切回离线演示；或清除浏览器对该页面的站点数据 |
| 答辩现场没有网络 | 直接使用默认离线演示模式，6 大场景 + 关键词兜底可完整演示 |

## 六、离线模式能回答哪些问题

不接模型时，内置答案覆盖：
- **6 大场景**：房东扣押金、兼职欠薪、合同问题、试用期辞退、虚假招聘、其他；
- **8 类关键词兜底**：消费 / 预付式退费、校园贷 / 高利贷、人身侵权 / 校园伤害、网络侵权（名誉 / 隐私）、知识产权 / 论文抄袭、房屋维修责任、劳动社保 / 仲裁、通用维权流程。

自由输入会先按关键词匹配场景 / 分类给出对应演示回答；匹配不到则给出通用四步维权建议。

## 七、费用、安全与合规

- **费用**：DeepSeek 按 token 计费，需账户有余额；日常演示咨询成本极低。
- **Key 安全**：API Key 仅保存在使用者本机浏览器中；请勿在公共 / 共用设备上保存，请勿把 Key 写入代码、截图或提交到仓库。
- **数据隐私**：开启云端模式后，提问文本会发送至 DeepSeek 官方服务器，请遵守其服务条款，勿输入身份证号等敏感个人信息。
- **免责**：AI 回答（无论离线还是模型生成）**仅供学习参考，不构成法律意见**；模型可能引用错误条号，正式用途请核对法条原文。重大事项请咨询执业律师或拨打 **12348** 法律援助热线。
