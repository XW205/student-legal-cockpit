# 法护启航 · AI 大模型接入说明

> 「法护启航」中有**两个功能**使用 DeepSeek 大模型，且**共用同一份配置**（AI 助手页 ⚙️ 设置）：
> - **🤖 AI 法律助手「法小航」**：双通道——🧪 离线演示模式（默认，6 大场景 + 关键词兜底，零网络可答辩）／🎓 DeepSeek 云端模型模式（回答任意法律问题，失败自动回退离线演示）；
> - **📄 AI 合同风险雷达**：粘贴合同全文或上传文件（浏览器本地抽取文字）后，由 DeepSeek 输出结构化风险报告；未配置 / 失败时提供「审查失败」页与离线演示报告兜底。
>
> 本文档介绍如何开启云端模型模式。无需后端、无需代理、无需 GPU。

---

## 一、架构

```
浏览器（index.html + styles.css + app.js）
   │  AI 助手页 ⚙️ 设置 → 选择「🎓 DeepSeek（云端模型）」→ 填入 API Key（配置存 localStorage）
   ▼
https://api.deepseek.com/v1/chat/completions   （DeepSeek 官方，OpenAI 兼容接口，浏览器直连）
   ├── 🤖 AI 助手：多轮对话（system「法小航」+ 最近 12 轮历史）→ Markdown 回答 + 法条卡片
   └── 📄 合同审查：合同文本（粘贴 / 文件本地抽取）→ JSON 结构化风险报告 → 渲染评分与风险条款

合同文件（PDF / Word / 图片 / TXT）
   └── 全程在浏览器本地解析（pdf.js / mammoth / Tesseract.js，按需从 CDN 加载）
       文件本身不上传，仅把抽取后的文字发送给 DeepSeek
```

- 页面直接调用 DeepSeek 官方接口，**本项目不包含任何后端服务**，也不需要自己部署模型。
- 接口为通用 **OpenAI 兼容协议**：把「服务地址 / 模型名称 / API Key」换成其他兼容服务，两个功能即可同时接入任意大模型（见第五节）。
- AI 助手未配置 Key、未联网或请求出错时，自动回退离线演示回答；合同审查未配置 / 出错时进入「审查失败」页，可重试或查看离线演示报告，演示流程不会中断。

## 二、接入步骤（约 3 分钟）

### 1. 获取 DeepSeek API Key
1. 访问 [platform.deepseek.com](https://platform.deepseek.com) 注册 / 登录；
2. 完成实名认证并充值（按量计费，演示咨询与合同审查用量很小，余额少量即可）；
3. 在「API Keys」页面创建一个 Key，形如 `sk-xxxxxxxx`，复制保存（**只显示一次**）。

### 2. 在网页中配置
1. 双击打开 `index.html`（或访问 [GitHub Pages 在线版](https://xw205.github.io/student-legal-cockpit/)），进入底部导航「**AI 助手**」；
2. 点右上角 **⚙️** 打开「AI 模型接入设置」；
3. 模式选择 **🎓 DeepSeek（云端模型）**；
4. 确认三项配置（一般保持默认）：
   - **服务地址**：`https://api.deepseek.com`（代码会自动补全 `/v1`）
   - **模型名称**：`deepseek-chat`（也可填 `deepseek-reasoner` 使用推理模型）
   - **API Key**：粘贴第 1 步的 `sk-...`
5. 点 **🔌 测试连接**：
   - 显示绿色「✅ 已连接！模型 deepseek-chat 可用」即成功；
   - 显示红色失败提示，按第六节排查；
6. 点 **💾 保存并应用**。

> 配置保存在**本机浏览器** localStorage（键 `deepseek_cfg_v1`），刷新 / 重开页面仍然有效；不会上传到任何服务器，代码中也不内置任何 Key。

### 3. 使用与切回
- AI 助手页顶部状态点：🟢「DeepSeek 已接入」/ ⚪「离线演示模式」；对话右上角标签同步显示 `🎓 DeepSeek` / `● 离线演示`。
- 合同审查页粘贴区下方有状态行：🟢「DeepSeek 已连接 · deepseek-chat」/ 🟡「已填 Key 但未启用」/ ⚪「未配置 DeepSeek」，后两者带「去启用 / 去配置」快捷按钮，点击直接跳转设置弹窗。
- 想切回离线演示：⚙️ → 选「🧪 离线演示模式」→ 保存即可，无需删除 Key（切回后合同审查将不能发起真实 AI 审查，仅可查看离线演示报告）。

## 三、工作机制（改代码前了解）

### 3.1 🤖 AI 助手（多轮对话）

| 环节 | 说明 |
|---|---|
| 请求地址 | `POST {服务地址}/v1/chat/completions`（OpenAI 兼容） |
| 请求内容 | `system` 系统消息（「法小航」角色：要求引用法条、分步骤、不足先追问、提示 12348、附免责声明）+ 最近 **12 轮**对话历史 |
| 参数 | `temperature 0.7`、`top_p 0.9`、`max_tokens 2048`、非流式 |
| 超时处理 | 120 秒超时；新提问会中断上一次未完成请求；请求失败 / 网络错误时，当前气泡提示原因，并**自动追加一条离线演示回答** |
| 空返回兼容 | `content` 为空时自动回退读取 `reasoning_content`（兼容 `deepseek-reasoner`）；`finish_reason=length` 时提示超长截断 |
| 回答渲染 | Markdown 经 `marked` 渲染（CDN 加载失败则纯文本展示）；回答中出现《民法典》第 x 条等引用时，自动从内置法条库 `LAW_DB`（30 条原文）匹配，追加可折叠「📖 法律依据」卡片 |
| 鉴权 | 有 Key 时带 `Authorization: Bearer <Key>`；本地模型可不填 |
| 测试连接 | `GET {服务地址}/v1/models`（9 秒超时），校验模型名是否在可用列表 |
| 相关代码 | `FUZI_CFG`（配置）、`FUZI_SYS`（系统提示）、`askModel()`（请求与回退）、`testFuziConnection()`（测试连接）、`LAW_DB` / `extractLaws()` / `appendLawCard()`（法条卡片）；变量名 `FUZI` 为历史命名，界面均显示 DeepSeek |

### 3.2 📄 AI 合同风险雷达（结构化审查）

完整链路：**输入合同文本 → 本地解析（如为文件）→ 截断保护 → DeepSeek 审查 → 解析 JSON → 渲染报告 / 失败兜底**。

| 环节 | 说明 |
|---|---|
| 文本来源 | ① 粘贴合同全文（`#contractText`）；② 上传文件经浏览器本地抽取文字；③ 「📋 填入示例租房合同」一键填充 |
| 请求地址 | 与 AI 助手相同：`POST {服务地址}/v1/chat/completions`，**共用同一份 Key / 地址 / 模型配置** |
| 请求内容 | 合同审查专用 `system` 消息（资深合同审阅助手角色，规定输出 JSON 字段与审查重点：违约金、押金、单方解除权、维修责任、费用、管辖、送达、空白条款等）+ 合同全文 |
| 参数 | `temperature 0.2`、`max_tokens 12000`、非流式、**`response_format: { type: 'json_object' }`**（强制 JSON）；150 秒超时；空输出自动重试 1 次（超长截断不重试） |
| 文本截断 | 合同文字超过 **12,000 字**自动截断并注明，仅分析前 12,000 字 |
| 返回 JSON 结构 | `{ "score": 0-100 整数(越高风险越大), "level": "低\|中\|高", "summary": "一句话总评", "high": 整数, "mid": 整数, "low": 整数, "risks": [{ "level": "high\|mid", "clause": "条款位置", "title": "风险标题", "reason": "风险原因", "fix": "修改建议", "law": "法律依据" }], "low_tips": ["低风险建议…"] }`；高中风险合计 ≤ 8 条、低风险 ≤ 6 条 |
| 报告渲染 | 综合得分圆环动画（≥70 红 / ≥45 黄 / 余绿）+ 签约建议 verdict + 高 / 中 / 低计数与筛选按钮联动 + 风险卡（风险原因 / 修改建议 / 法律依据，可展开）+ 低风险折叠块；支持导出 TXT |
| 失败兜底 | 未配置 / 未启用 DeepSeek、网络错误、超时、JSON 解析失败 → 进入「😥 AI 审查失败」页，展示具体原因，提供「↻ 重新审查 / ✏️ 返回修改文本 / 🧪 查看离线演示报告」三个操作 |
| 离线演示报告 | 内置示例租房合同报告（72/100，🔴3 / 🟡5 / 🟢12），数据为 `RISK` + `LOW_TIPS`，仅展示效果、不代表本次审查结果 |
| 相关代码 | `analyzeWithDeepSeek()`（审查请求）、`callDeepSeekChat()`（通用请求封装）、`parseContractReport()`（JSON 解析）、`startScan()`（扫描入口与状态机）、`showFailStage()` / `showReportAI()` / `showReport()`（失败页 / AI 报告 / 离线报告）、`SAMPLE_CONTRACT`（示例合同）、`RISK` / `LOW_TIPS`（离线演示数据） |

## 四、合同文件本地解析说明

上传文件后，解析**全部在浏览器本地完成**（文件不经过任何第三方服务器），解析库按需从 jsDelivr CDN 加载：

| 文件类型 | 解析方式（CDN 库） | 说明 |
|---|---|---|
| PDF（.pdf） | `pdf.js`（pdfjs-dist 3.11.174）抽取文字层 | 文字型 PDF 可直接抽取；**扫描件 / 图片版 PDF 无文字层**会提示改传图片 OCR 或粘贴全文 |
| Word（.docx） | `mammoth.js`（1.6.0）抽取纯文本 | 仅支持 .docx；**旧版 .doc 不支持**，请另存为 .docx 或粘贴全文 |
| 图片（.jpg/.jpeg/.png/.webp） | `Tesseract.js`（5.0.5）OCR，语言 `chi_sim+eng` | 首次使用需下载中文识别模型（进度实时显示），请保持网络畅通；识别效果取决于图片清晰度 |
| 文本（.txt/.md） | 浏览器 `FileReader` 直接读取（UTF-8） | 无外部依赖 |

限制与约定：

- 文件大小 ≤ **20MB**；解析超时 **90 秒**（OCR 大图可能较慢）；抽取文字统一截断至 **12,000 字**后送审；
- 解析库仅在首次上传对应格式时加载，加载失败会提示「可粘贴全文后审查」；
- 隐私：文件内容不出本机，发送给 DeepSeek 的只有抽取后的合同文字；
- 答辩断网建议：提前在有网环境打开过一次页面（让浏览器缓存 CDN 库），或直接使用「粘贴合同全文」路径演示。

## 五、接入其他 OpenAI 兼容服务（进阶）

设置弹窗里的三项配置可指向**任何 OpenAI 兼容接口**，AI 助手与合同审查同时生效，无需改代码：

| 目标 | 服务地址示例 | 模型名称示例 | 备注 |
|---|---|---|---|
| DeepSeek（默认） | `https://api.deepseek.com` | `deepseek-chat` | 需官方 API Key；支持 JSON 模式 |
| 本地 vLLM 服务 | `http://127.0.0.1:8000/v1` | 与 `--served-model-name` 一致 | Key 随意填；建议选支持 JSON / 指令跟随强的模型；见下方 CORS 说明 |
| 本地 Ollama | `http://127.0.0.1:11434/v1` | `qwen2.5:7b` 等 | 需设置 `OLLAMA_ORIGINS=*` |
| 其他云端兼容服务 | 以各厂商文档为准 | 以各厂商文档为准 | 注意计费、隐私条款与是否支持 `response_format: json_object` |

> 合同审查依赖模型返回 JSON：代码已做容错（自动剥离 ```json 代码块、截取首个 `{...}` 解析），即使目标服务不支持强制 JSON 模式，只要模型能在回答中给出 JSON 对象即可正常解析；解析失败会进入审查失败页而非白屏。

**CORS（跨域）注意**：用浏览器直接打开本地 `index.html`（`file://`）时，请求来源为 `null`：
- vLLM 启动需加参数：`--allowed-origins "*"`（或 `"null"`）；
- Ollama 需设置环境变量 `OLLAMA_ORIGINS=*` 后重启；
- DeepSeek 等云端服务已允许浏览器直接调用，无需处理。
- 若目标服务无法开启 CORS，才需要自建一个简单的转发代理（本仓库当前不含后端代码）。

## 六、常见问题排查

| 现象 | 原因与处理 |
| --- | --- |
| 测试连接 ❌，提示连接失败 / 401 | API Key 错误、未复制完整，或账户欠费；到 platform.deepseek.com 核对 Key 与余额 |
| HTTP 404 / 模型列表里没有该模型 | 模型名称拼写错误，默认应为 `deepseek-chat`；测试连接成功提示中会列出可用模型名 |
| HTTP 400 | 请求参数被服务拒绝（如模型名与服务不匹配）；核对模型名称 |
| AI 助手提问后提示「暂时无法获取回答」并自动回退 | 网络不通 / 超时（120s）/ 服务繁忙；页面会自动给出离线演示回答，可稍后重试 |
| 合同审查点「开始扫描」直接进入失败页，提示未配置 / 未启用 | DeepSeek 模式未开启或 Key 为空；按失败页提示或合同页状态行的「去配置」按钮，到 ⚙️ 设置中启用 DeepSeek 并保存 |
| 合同审查失败提示「无法解析模型返回的 JSON」 | 模型未按约定返回结构化结果；点「↻ 重新审查」即可（代码会自动重试一次），或换用 `deepseek-chat` |
| 合同审查等待较久（30~60 秒） | 长合同 + max_tokens 12000 生成较慢，属正常现象；超时为 150 秒 |
| 上传 PDF 提示「可能是扫描件（无文字层）」 | 该 PDF 由图片构成、无文字层；请把合同页截图后传图片走 OCR，或直接粘贴合同全文 |
| 上传 .doc 提示无法解析 | 旧版 .doc 格式不支持；用 Word 另存为 .docx，或粘贴全文 |
| 图片 OCR 很慢 / 卡在识别中 | 首次需下载中文 OCR 模型；请等待进度条，或改用粘贴全文；90 秒超时会提示重试 |
| 审查结果只覆盖合同前半部分 | 合同超过 12,000 字被自动截断；可把合同拆分为多段分别审查 |
| CORS / 跨域报错 | 仅出现在自建 / 本地服务：按第五节配置 `allowed-origins`；DeepSeek 云端不会出现 |
| 换了浏览器 / 电脑要重新填 Key | 配置存在各自浏览器的 localStorage 中，属于预期行为 |
| 想彻底清除配置 | ⚙️ 切回离线演示；或清除浏览器对该页面的站点数据 |
| 答辩现场没有网络 | AI 助手使用默认离线演示模式（6 大场景 + 关键词兜底）；合同审查可点「🧪 查看离线演示报告」展示完整报告效果 |

## 八、费用、安全与合规

- **费用**：DeepSeek 按 token 计费，需账户有余额；日常演示咨询与合同审查成本极低（合同审查 max_tokens 12000，长合同单次费用略高于问答）。
- **Key 安全**：API Key 仅保存在使用者本机浏览器（localStorage 键 `deepseek_cfg_v1`）；请勿在公共 / 共用设备上保存，请勿把 Key 写入代码、截图或提交到仓库。
- **数据隐私**：开启云端模式后，**提问文本与合同文本**会发送至 DeepSeek 官方服务器，请遵守其服务条款，勿输入身份证号、真实姓名等敏感个人信息；合同文件本身只在浏览器本地解析、不上传。
- **本机档案数据**：「我的权益」中的注册档案与证据材料仅保存在本机浏览器（localStorage），不会发送到任何服务器；演示版密码为简单哈希、非加密存储，请勿在公共设备填写真实信息或上传敏感材料，正式产品需加密存储与实名认证。
- **免责**：AI 回答与 AI 合同审查报告（无论离线还是模型生成）**仅供学习参考，不构成法律意见**；模型可能引用错误条号，正式用途请核对法条原文。重大事项请咨询执业律师或拨打 **12348** 法律援助热线。
