## ✨ 项目简介

「法护启航」是一个**原生三件套、零构建、可双击运行**的 Web 前端原型，包含 5 个页面 + 底部固定导航，面向在校大学生常见的法律风险场景提供演示与引导。代码按 `index.html`（结构）/ `styles.css`（样式）/ `app.js`（逻辑）三个文件组织。

- 🧪 **开箱即用**：默认离线演示模式，无需安装、无需服务器，断网可答辩（AI 问答 / 风险测试 / 风险地图 / 档案等核心动线不依赖网络）；
- 🎓 **两个场景接入真实大模型**：在设置中填入 DeepSeek API Key 后，**AI 法律助手**与 **AI 合同风险审查**均由真实大模型驱动（OpenAI 兼容接口，也支持其他模型服务），失败自动回退离线演示；
- 📂 **合同文件浏览器本地解析**：PDF / Word / 图片 / TXT 在浏览器本地抽取文字（pdf.js / mammoth / Tesseract OCR，按需从 CDN 加载），文件不上传，仅把抽取后的合同文字发送给模型；
- 🗂️ **个人法律档案本机留存**：注册登录、证据材料上传存证、证据链一键汇总，数据均保存在本机浏览器 localStorage，刷新不丢失；
- 📱 **移动端风格**：手机驾驶舱式布局，蓝灰科技风视觉，适合课堂演示与答辩；
- 🌐 **已部署 GitHub Pages**：支持在线访问，也可下载源码双击运行。

## 🔌 AI 大模型接入

DeepSeek 为**双通道、双场景**设计：AI 助手与合同审查**共用同一份模型配置**（AI 助手页 ⚙️ 设置）。

- **🧪 离线演示模式（默认）**：AI 助手内置 6 大场景标准答案 + 7 类关键词兜底（消费退费、校园贷、人身侵权、网络侵权、知识产权、房屋维修、劳动权益）+ 通用维权建议，零网络零成本；合同审查提供一份内置离线演示报告（72 分示例租房合同报告）用于展示效果；
- **🎓 DeepSeek 云端模型模式**：AI 助手页点右上角 **⚙️** → 选择「DeepSeek（云端模型）」→ 填入 [platform.deepseek.com](https://platform.deepseek.com) 的 API Key → 🔌 测试连接 → 💾 保存即可。保存后：
  - **AI 助手**：真实大模型回答任意法律问题，系统提示要求引用具体法律名称与条号；
  - **合同审查**：粘贴合同文本或上传文件（本地抽取文字）后，由 DeepSeek 输出**结构化 JSON 风险报告**（0–100 风险评分 + 高 / 中 / 低风险计数 + 逐条风险原因 / 修改建议 / 法律依据）。

接入要点：

- 浏览器**直连** DeepSeek 的 OpenAI 兼容接口（`https://api.deepseek.com/v1`），**无后端、无代理、无需 GPU**；
- API Key 仅保存在本机浏览器 localStorage（键 `deepseek_cfg_v1`），代码不内置任何 Key；
- 请求失败 / 超时 / 断网时**自动回退**：AI 助手追加一条离线演示回答；合同审查进入「审查失败」页并可查看离线演示报告，演示不中断；
- 文件解析库（pdf.js / mammoth / Tesseract.js）与 Markdown 渲染库（marked）按需从 CDN 加载：离线时聊天气泡自动降级为纯文本展示，文件解析不可用时可改用「粘贴合同全文」；
- 服务地址与模型名可自定义，支持任何 OpenAI 兼容服务（本地 vLLM / Ollama 等，需处理跨域）。

📖 完整步骤、合同审查链路、文件解析说明、参数与故障排查：[**README-AI接入.md**](./README-AI接入.md)

## 🛠️ 技术栈

- **原生 HTML + CSS + JavaScript**，无框架、无构建步骤；样式 / 脚本 / 结构三文件分离，便于多人分工与代码评审；
- **CDN 按需加载**（仅做能力增强，加载失败自动降级，不阻断主流程）：
  - `marked`：聊天气泡 Markdown 渲染（加载失败回退纯文本）；
  - `pdf.js`：PDF 文字层抽取；`mammoth`：Word（.docx）文字抽取；`Tesseract.js`：图片 OCR（中文简体 + 英文）；
- CSS 设计令牌（`:root` 变量）统一配色与风险语义色（红 / 黄 / 绿）；
- 数据与逻辑分离：页面数据集中在 `SCEN` / `RISK` / `LOW_TIPS` / `MAP_DATA` / `LAW_DB` / `QUIZ` 等 JS 对象中，替换数据即可接真实后端；
- AI 接入使用标准 **OpenAI 兼容协议**（`/v1/chat/completions`）；合同审查通过 `response_format: { type: 'json_object' }` 获取结构化报告，前端解析 JSON 渲染；
- 本机数据（localStorage）：`deepseek_cfg_v1`（模型配置）、`fahq_profile_v1` / `fahq_session_v1`（法律档案与登录态）、`fahq_evidence_v1`（证据材料）。
