## ✨ 项目简介

「法护启航」是一个**单文件、零依赖、可双击运行**的 Web 前端原型，包含 5 个页面 + 底部固定导航，面向在校大学生常见的法律风险场景提供演示与引导。

- 🧪 **开箱即用**：默认离线演示模式，无需安装、无需服务器、断网可答辩；
- 🎓 **可接真实大模型**：在设置中填入 DeepSeek API Key，AI 助手即可回答任意法律问题（OpenAI 兼容接口，也支持其他模型服务），失败自动回退离线演示；
- 📱 **移动端风格**：手机驾驶舱式布局，蓝灰科技风视觉，适合课堂演示与答辩。

## 🔌 AI 大模型接入

AI 助手为**双通道**设计：

- **🧪 离线演示模式（默认）**：内置 6 大场景标准答案 + 8 类关键词兜底（消费退费、校园贷、人身侵权、网络侵权、知识产权、房屋维修、劳动权益等），零网络零成本；
- **🎓 DeepSeek 云端模型模式**：AI 助手页点右上角 **⚙️** → 选择「DeepSeek（云端模型）」→ 填入 [platform.deepseek.com](https://platform.deepseek.com) 的 API Key → 🔌 测试连接 → 💾 保存即可。

接入要点：

- 浏览器**直连** DeepSeek 的 OpenAI 兼容接口（`https://api.deepseek.com/v1`），**无后端、无代理、无需 GPU**；
- API Key 仅保存在本机浏览器 localStorage，代码不内置任何 Key；
- 请求失败 / 超时 / 断网时**自动回退**离线演示回答，演示不中断；
- 服务地址与模型名可自定义，支持任何 OpenAI 兼容服务（本地 vLLM / Ollama 等，需处理跨域）。

📖 完整步骤、参数说明与故障排查：[**README-AI接入.md**](./README-AI接入.md)

## 🛠️ 技术栈

- **原生 HTML + CSS + JavaScript**，无框架、无构建、无外部依赖；
- CSS 设计令牌（`:root` 变量）统一配色与风险语义色（红 / 黄 / 绿）；
- 数据与逻辑分离：页面数据集中在 `SCEN` / `RISK` / `MAP_DATA` 等 JS 对象中，替换数据即可接真实后端；
- AI 接入使用标准 **OpenAI 兼容协议**（`/v1/chat/completions`）。
